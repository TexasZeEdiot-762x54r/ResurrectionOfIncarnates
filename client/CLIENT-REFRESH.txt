RECOMMENDED: CLEAN REBUILD (rules out older executable/script patches too)
1. Close your old game and its launcher. Keep the old installation untouched.
2. Extract this ZIP into a NEW empty folder, not inside another patch's tools.
3. Start Steam, logged in to your own licensed account. Run Setup.bat.
   Select your NORMAL Steam game install when asked for roi.exe, NOT an old
   patched copy. The full historical Steam depot is selected separately.
   Setup needs about 11 GB of space for a new game copy. It verifies the package
   and source executable, copies your assets, installs metadata and rebuilds.
4. Run Online - Steam.bat from THIS new folder. It selects the public service
   and starts the game; do not start the old shortcut or Steam Discovery.
5. For the host on the server's LAN, use Online - Steam (LAN).bat instead.
   These two launchers reach the same shared room list. Try a newly created room.
