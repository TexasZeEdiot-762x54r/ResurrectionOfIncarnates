Customization labels, 2026-10-19

The server used quote ID 0 for every cosmetic's name and description. That ID
resolved to unrelated dialogue ("Here we go. Think you can keep up?"). This
affected all characters, not only Fenrir.

Items now use numeric quote IDs pointing to distinct model/colour labels, such
as "Costume 001 - Colour 02", "Accessory 003", and "Head Accessory 003".
Model 000 / colour 00 base items use the original "Default" quote. Colour
labels are one-based for readability; underlying model/texture IDs do not change.

Names now distinguish footage-verified mappings, player-supplied references,
provisional appearance matches, and unresolved revival labels. This is NOT a
complete recovery of the original cosmetic-name mapping. Original names are
present in common_text, but their exact links to many models/colours remain
unverified. No names are assigned by guessed release order. Item descriptions
identify player references and provisional matches.

Setup / Apply Update closes or requires closing the client, backs up archive
014, and changes only reviewed untranslated cosmetic-placeholder text cells.
Original translated names, dialogue, skill-cube text and the diagnostic cube
labels are preserved. The patch fits inside the existing archive entry, changes
no archive index or game executable, and does not touch profiles, item/hold IDs,
ownership, equipment, thumbnails, saved outfits, levels, LP or reward policies.

Generated customize-labels.json contains only reviewed label metadata. It does
not contain credentials, profiles or game assets. Reapplying the same update is
a no-op. Unexpected text/layout or insufficient allocation aborts before writing.

Restart the client after applying: customization masters and text are cached.
