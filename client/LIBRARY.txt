INSTALLATION
Use the complete client source/ZIP; retain tools/library, text.json and catalogue.
An existing installation needs the new local server, Library handler/assets,
play session and Library session module, then a normal client restart.
No shared-server/container restart or account/profile changes are needed.
Apply Update/Setup also verifies exe/bin/cefserver.exe and its dependencies.
If missing, setup_library.py copies only hash-verified files from the player's
supported original Steam installation, refusing different existing binaries.
The browser binaries themselves are not distributed. The original browser is
obsolete: the supplied pages use only local HTML/CSS/images, not remote scripts.
The first native test remained black because this helper directory was absent;
URL changes alone cannot render pages without that separate browser process.
Do not change firewall rules or forward port 52710. Library assets are served
only by the launcher's existing loopback HTTP service; no Internet access is
needed to browse them. Normal Steam/game services retain their requirements.

The Library HTTP routes are read-only and do not invoke profile/game handlers.
Only explicit catalogue assets are accessible; traversal, arbitrary files,
external URLs, unsupported languages and unsafe queries are rejected.
The pages use plain HTML/CSS and same-origin images with no scripts or trackers.
